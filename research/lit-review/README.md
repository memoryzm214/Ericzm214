## 三步上手

**1）导入文献管理器**

Zotero → 文件 → 导入 → 选 `refs.bib`。
导入后全选条目 → 右键 → **Find Available PDFs**，开放获取的会自动下载。

**2）批量抓 OA 全文**

```bash
cd research/lit-review
bash download_oa_pdfs.sh
```

脚本可反复运行（已下载的自动跳过），失败的条目会在结尾汇总，照 DOI 手动点一下即可。

**3）先读主文档的第 6 节「如果只读10篇」**

按那个顺序读完，CGEL 模型每一环都有量表、每条假设都有先例、每个方法选择都有辩护。大约两周的量。

## 需要你知道的四点局限

1. **PDF 没能在建库时抓下来。** 建库所在的远程环境出网被网络策略限制（arXiv、MDPI、Frontiers、Nature、ACL、Crossref、Semantic Scholar 全部 403），所以文献是通过检索确认的，全文要靠上面的脚本或 Zotero 在你自己机器上取。

2. **元数据核验程度不一。** 能从 URL 直接推出 DOI 的（Frontiers / MDPI / Nature / ACM / Emerald / Sage / T&F / Springer）都写了；**推不出的宁可留空也没有凭记忆填**——错的 DOI 比缺的 DOI 更麻烦。`refs.bib` 里标 `[WAIT-VERIFY]` 的字段（多为作者、卷期）请在导入后用 DOI 更新。

3. **中文文献覆盖不足。** CNKI / 万方 / 维普在建库环境里访问不到，D 组的中文文献是从公开网页找到的。**《装饰》《南京艺术学院学报》《现代传播》《新闻与传播研究》《图书情报工作》这几本必须你自己在 CNKI 补检**——申报武汉市社科基金时中文 C 刊是刚需。

4. **2026 年的文献不要当理论依据引。** A 组和 B 组里有不少 2026 年的 Frontiers / MDPI 论文，时效性最好但被引数据未形成、质量参差。当「研究现状」引，理论依据一律落在 A-3 和 B-3 的经典上。

## 维护建议

- **每年 9 月**刷新一次 A 组、B 组的「近三年」部分；经典层（A-3、B-3、C 组量表）保持不动。
- D-2（长江文化蓝皮书）每年更新，用来判断长江文化研究的竞争格局。
- 新增文献时沿用现有编号规则（组-子组-序号），并在主文档里补齐「理由」一栏——**没有理由的条目不要进库**，那是文献堆不是文献库。
