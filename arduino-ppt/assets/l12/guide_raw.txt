                       按键模块实验
按键模块介绍
 数字 I/O 端口的含义是 INPUT 和 OUTPUT 接口，在以前的 LED 灯实验中，我们只使用 GPIO 的
OUTPUT 功能。 现在让我们尝试在 Arduino 中使用 I / O 的 INPUT 功能，即该功能是在本实验中从外
 部设备读取输出值。 我们使用按键和 LED 灯来完成使用 INPUT 和 OUTPUT 作为组合的实验。




实验目的
我们将按键连接到 D7 号接口，红灯连接到 D11 号接口（Arduino 控制器中的所有 D0-D13 数字 I / O
接口可用于连接按键和指示灯，但尽量不要选择数字 D0 和 D1 接口，因为 D0 和 D1 功能复用，除了
I / O 端口功能外，它们还用作串行通信接口。下载程序时，设备正在与 PC 通信。所以我们应该保留
D0 和 D1 接口 为了避免插入线路的麻烦，我们不选择 D0 号和 D1 号接口。

    通过分析电路我们可以知道，当按下按钮时，D7 号接口处于高电平，它将 D11 号输出引脚置高

电平，这可以使灯亮。 当 D7 号接口读为低电平时，D11 号输出保持低电平，此时指示灯熄灭。 原

int led_out = 11 ; //GPIO 11 LED pin
int keypad_pin = 7; //GPIO 7 key pin
int value;
void setup()
{
    pinMode(led_out,OUTPUT);                     // init led pin output
    pinMode(keypad_pin,INPUT);          // init key pin input
     digitalWrite(led_out,LOW);
}
void loop()
{
        value = digitalRead(keypad_pin);    // read key pad pin vaule
        if( value == LOW )
        {
            digitalWrite(led_out,HIGH);      // if key value is down turn on LED

       }
       else
       {
              digitalWrite(led_out,LOW);   // if key value is down   turn off LED
       }
}

                         触摸开关模块实验
触摸开关模块介绍
 触摸开关模块是一个基于触摸检测 IC（TTP223B）的电容式点动型触摸开关模块。常态下，模块
输出低电平，模式为低功耗模式；当用手指触摸相应位置时，模块会输出高电平，模式切换为快速模式；
当持续 12 秒没有触摸时，模式又切换为低功耗模式。可以将模块安装在非金属材料如塑料、玻璃的
表面，另外将薄薄的纸片（非金属）覆盖在模块的表面，只要触摸的位置正确，即可做成隐藏在墙壁、
桌面等地方的按键。

               倾斜开关模块实验
倾斜开关模块介绍
  倾斜开关模块也称为滚珠开关，滚珠开关也叫钢珠开关，珠子开关，其实都是震动
开关 的一种只是叫法不一样，都是通过珠子滚动接触导针的原理来控制电路的接通或
者断开的。 当倾斜传感器感应到倾斜时，模块会输出低电平信号，否则输出高电平。
1、SW-520、SW-520D 为滚珠型倾斜震动感应单方向性触发开关。
2、当产品向帽盖端倾斜、倾斜角大于 10 度时，为开路 OFF 状态， 当产品水平状态
发生倾斜改变(并 且引线平行于平面方向，上 下高度一样)，触发端(镀金引脚端 A
与 B)低于水平倾斜角大于 10 度角时，为闭路 ON 状态。

实验原理
 利用倾斜开关模块的工作特性, 当在电路板在静止状态时, 倾斜开关模块处于闭合状态,当有外力
触碰到了电路板致使其倾斜开关里面的滚珠和导线断开接触从而断开电路,此时触发报警,LED 亮,蜂
鸣器响;当断开模块恢复到静止状态时,LED 熄灭,蜂鸣器不响.
