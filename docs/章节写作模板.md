# 章节写作模板与句式库

配套《写作风格指南》使用。左侧为骨架，右侧方括号内为需替换的内容。直接套写即可保持与既有两卷一致的体例。

---

## 一、理论/论证章模板（适用于第一至第三章）

```
第X章　[章名]

［章首导语，1 段，150–250 字，不编号］
　　[上章结论的一句话回指]，[本章任务的判断句]。本章[首先/将]…；继而…；最后…。
　　本章的论述停留于[层面]，其[另一层面]的处理留待第[N]章。

X.1　[节名]
［节首导语 1 段］
　　[为什么这一节必须先做：倘若…则…；唯有…后续讨论方有立足之地。]
　　有鉴于此，本节的任务在于[三项，逐一列出]。

X.1.1　[目名]
　　［分类依据段］既有的[某某]叙述多以[旧依据]为分期依据，此类分期长于[优点]，却不易显示[缺陷]。本书因而改以[新依据]为分期依据，将…划分为[A]、[B]与[C]三个阶段。此种分期的着眼点不在[X]而在[Y]。
　　须先予说明者有二。其一，[三阶段并非截然断裂…]。其二，[就今日的实际场景而言，三者往往并存…]。此种[现象]本身即构成一项值得注意的事实——它意味着[含义]。

　　其一，[A]。[定义与技术形态]。[其特性]。[就判断而言，此一阶段…]。
　　其二，[B]。[同构展开]。[然而，…其缘由在于：…]。[此项要求本身具有一种不易察觉的[价值]，值得专门指出。]
　　其三，[C]。[同构展开]。[此一阶段与前两阶段的分野，不在于…亦不在于…而在于一项此前从未出现的特性：…]。
　　由此还派生出一重悖论，姑称之为[某某]的悖论。[展开]。

　　［比较段］三个阶段的比较，可自四个维度展开（如表 X-1 所示）。就[维度一]而言，依次为…；就[维度二]而言，…；就[维度三]而言，…。而在诸维度之中，最具决定意义者是第四项，即[维度四]。
　　［归结段］要之，[核心判断]，是本书全部问题的[技术/学理]根源。后文所论[A]为何…、[B]何以…，皆可上溯至这一变化。

X.N　本节归结：[一句话判断]
　　本节的考察指向一个基本判断：[判断句]。此一判断可自本节的三项发现予以支撑。
　　第一，[发现一]。……
　　第二，[发现二]。……
　　第三，[发现三]。……
　　凡此三者共同表明，[回扣本章开头的命题]；当前所需要的既不是[极端一]，亦不是[极端二]，而是[本书的路径]。
　　最后须交代本节论述的限度。本节所做者为[X]层面的描述与归纳，其材料来源为[…]；它足以确立[A]，却不足以解释[B]。[B] 须俟第[N]章展开。
```

## 二、实证/实验章模板（适用于第四至第七章）

```
第X章　[章名]

［章首导语］
　　[对象]在[领域]中发挥着至关重要的作用。为探究[问题]，本章将率先确定[样本与变量]，并通过[方法一]、[方法二]及[方法三]三种方式分别对[目标量]进行[表征/量化]。

X.1　[样本与变量的筛选]
X.1.1　[样本筛选]
　　为确保后续研究的顺利开展，需要优先确定实验中所需的[样本]。本书将遵循以下[四]项原则：第一，…；第二，…；第三，…；第四，必须避免[安全隐患]。
　　［逐项落实，含专家二次筛选］此外，考虑到[过多样本易造成受试者认知及记忆负担]，本研究又邀请了[专家身份]对[N]项预选[对象]进行二次筛选。[专家意见的直接转述]。

X.N　本章小结
　　本章通过[方法]揭示了[结论]，获取了[产出物]。此外，为深化[产出物]的应用价值，本书基于……构建了[工具]。最后，本书还以[案例]为例，通过[评估标准一]、[二]及[三]，证实了[产出物]在[场景]中的可用性和有效性。
```

## 三、句式库（按功能分类，可直接取用）

### 3.1 提出问题 / 立必要性

- 上节所提出的[三项特征]，尚属对问题性质的判断，其能否成立，取决于[X]究竟以何种方式进入了[Y]。
- 此一厘清并非仅为铺陈背景，而是关涉本书立论的成立与否：倘若[X]不过是[寻常情形]，则所谓[危机]便是一种夸大其词的忧虑；唯有证明[此次不同]，后续关于[A]与[B]的全部讨论方有立足之地。
- 本书之所以以整部著作的篇幅处理这一问题，尚有一层学科层面的理由。

### 3.2 下定义 / 命名

- 据此，本书提出并使用[概念]这一核心概念，用以指称[对象]在[条件]下，仍能[能力一]、[能力二]、[能力三]，从而[目的]的能力。
- 本书所称[概念]，指[主体]在[过程]中就[对象]作出[动作]并承担其后果的[范畴]。它具有三项不可化约的特征：一为[X]性，……；二为[Y]性，……；三为[Z]性，……。正是第三项特征，使[本概念]区别于[相邻概念]。
- 本书将[概念]操作化为三个可观测的维度。其一为…；其二为…；其三为…。
- 须予强调的是，本书在中性意义上使用这一概念：[X]本身既非缺陷亦非过错，而是[适应性策略]；构成问题的乃是[X]的持续性、无边界性与不可察性。

### 3.3 辨析 / 划界

- 在概念使用上，尚有三组区分需要预先澄清。其一，[A]不等同于[B]。……其二，……其三，……
- 此处须与[相邻现象]加以辨析。[传统情形的特点]……而[新情形]则……。前者是可以走出的路径，后者则是难以察觉的引力场。
- 二者虽有关联，其机制却截然不同，不宜混用。
- 二者形似而实异，却极易在[效率]的名义下相互混淆。

### 3.4 承认限度 / 悬置

- 最后须交代本节论述的限度。本节所做者为[X]，它足以确立[A]，却不足以解释[B]。
- 凡属推论者称其为推论，凡待检验者明言其待检验。
- 本书所提供者，是一个足够清晰因而具有可证伪性的框架，而非一个业经数据充分证实的结论。
- 但[现象 A] 与 [现象 B] 之间[何以不一致]，其中原因暂不明晰。
- 单一案例不足以证明框架的普遍有效性，却足以显示框架能否被实际使用。

### 3.5 转折与推进

- 然而，……其缘由在于：……
- 惟须注意，……存在一项特有风险，即……
- 惟须指出，此环节的[渗透]虽浅，其被绕过的风险却在上升。
- 尤须注意的是，……并不因[使用者意识到它的存在]而自动解除。
- 尚须补充的是，[征候]在不同主体之间的分布并不均匀。
- 需要说明的是，本书无意汇入笼统的[某某]论。

### 3.6 归结

- 要之，[核心判断]，是本书全部问题的[技术]根源。
- 凡此三者共同表明，……
- 此二项特征共同表明，……
- 综观[五个环节]，[渗透]的形态呈现出两项特征。第一，……第二，……
- 由此可见，……（实证章用）
- 综上所述，……（实证章用）

### 3.7 图表引称

- ……与国民经济、国防建设和人民生活有着密不可分的关系（如图 1-1 所示）。
- 表 5-2 显示了[N]名受试者对[…]的评估均值，即[…]的最终结果。
- 如表 6-1 所示，在[…]的相关性分析结果中，……
- 本研究基于 Pearson 相关系数绘制了要素间的相关性热图，如图 6-1 所示。
- ……具体内容如表 5-1 所示。

### 3.8 与既有研究对照

- 该相关性分析结果与 [某某] 认为"[观点]"的研究结论保持一致。
- 此结论也丰富了过往研究中[旧结论]的研究结果。
- 本书的相关性研究结果也与过往研究结论存在部分差异。在以往研究中，……。但在本研究中以上两组要素之间的相关性均不显著，而造成以上差异的原因目前尚不明确/很可能与[原因]有关。
- 而这一结论在以往研究中尚未提及。

## 四、结论章模板

```
结　论与展望

N.1　研究结论
　　［问题重述］[对象]是[价值]，……。因此，探讨[问题]刻不容缓。为此，本书对[领域]的国内外研究内容进行了总结，从而发现仍存在以下问题。首先，……。其次，……。最后，……。
　　［本书主张与子问题］本书认为影响[问题]的主要原因在于[核心症结]。因此，本书以[视角]为媒介，探讨了[主问题]，并将其划分为三个子研究问题：第一，……；第二，……；第三，……。本书的主要研究结果如下：
　　1. ……
　　2. ……（1）……（2）……
　　3. ……
　　4. ……

N.2　主要创新点
　　本书的创新点主要集中在理论、方法及实践三个方面。
　　在理论创新中：（1）……（2）……（3）……
　　在方法创新中，……其创新性主要表现在以下两点。首先，……。其次，……。
　　在实践创新中，……

N.3　反思与展望
　　本书……实现了一定的突破和创新。但回顾整个研究过程，本书仍需要在未来工作中……。具体不足之处主要表现在：
　　1. ［样本与变量受限］受制于……等多种因素的影响，……在种类和数量上均相对受限。因此，……
　　2. ［情境单一］……仅考虑了单一情况下……。因此，在本书研究基础上可在后期研究中考虑……
　　3. ［受试者背景单一］……所招募的大部分受试者均来自同一地区……
　　4. ［未纳入的调节变量］本书对研究中可能涉及的年龄、性别及……是否对结果产生影响暂未讨论。
　　5. ［产出物待完善］……有待进一步完善。
　　总而言之，[一句收束]。希望本书的研究成果能为[更大的目标]作出些许贡献。
```

## 五、投稿/定稿前自检清单

- [ ] 章首导语、节首导语、本章小结三件套齐备
- [ ] 每处分类之后有「须先予说明者有二/关于这一划分，须作两点说明」
- [ ] 每处比较之后指认了「最具决定意义者」
- [ ] 每节收尾有限度声明
- [ ] 自称统一为「本书」
- [ ] 三项并置处，列完有收束句
- [ ] 图题在图下、三行（中文题 / 英文题 / 来源），表题在表上、三行
- [ ] 图号、表号连续无重号无缺号；与插图索引、附表索引逐条对账
- [ ] 续图/续表标「（续）」；续表重复表头
- [ ] 「作者自绘」用词统一
- [ ] 数值统一保留两位小数；量纲首次出现时括注范围
- [ ] 统计报告链条完整：正态性 → 方差分析 → 齐性 → 事后检验
- [ ] 相关系数分级用词符合七级标准，且均已满足 P＜0.05
- [ ] 结论强度用词未越级（证明 / 表明 / 显示 / 提示 / 可推断 / 尚不明确）
- [ ] 术语首见处括注英文与缩写；人名中译名 + 括注外文年份
- [ ] 参考文献分英文/中文两区，区内按文献类型分类，GB/T 7714 格式
- [ ] 问卷全文入附录 A，正文以「（问卷见附录 An）」引称
- [ ] 涉及个人/机构信息已匿名化并作声明
