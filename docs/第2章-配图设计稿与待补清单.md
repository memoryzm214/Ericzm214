## 一、配图设计稿（6 幅）

图题一律置于图下，三行：中文题 / 英文题（Title Case）/（图片来源：作者自绘）。以下为绘制依据，画好后按正文中「［此处插入图2-X］」的位置替换即可。

### 图2-1　认知卸载的谱系与判断卸载的位置
**位置**：2.1.2 节末，表2-2 之后
**类型**：时间轴 + 分叉结构图
**结构**：
- 上半部为一条自左向右的时间轴，依次标注四个节点：交互记忆系统（韦格纳，1985）→ 延展心智（克拉克与查尔默斯，1998）→ 搜索引擎与记忆（斯帕罗等，2011）→ 认知卸载的系统化（里斯科与吉尔伯特，2016）。四个节点下方统一加一条横向色带，注明「共同对象：记忆的外部化」。
- 时间轴右端向下分出一支，以不同色相标出「判断的外部化（本书对象）」，注明「既有研究尚未充分处理」。
- 两支之间用一组对照标签连接：左支「内容仍在外部载体 → 可回取」，右支「能力本身萎缩 → 不可回取」。
**要点**：分叉必须画在时间轴末端而非并列于起点，以显示判断卸载是既有谱系的延伸而非另起一路；两支的视觉权重不对等，右支加重。

### 图2-2　卸载决策中收益与代价的不对称结构
**位置**：2.1.4 节，第二段之后
**类型**：双轴时间曲线图
**结构**：
- 横轴为时间（自「单次决策时刻」向右延伸至「数月—数年」），纵轴为「个体可感知的量级」。
- 收益曲线：自决策时刻起即跃升至高位并保持，标注「即时、确定、可直接感知」。
- 代价曲线：自决策时刻起贴近零位缓慢爬升，在横轴中后段才越过一条水平虚线，虚线标注「个体感知阈值」，越过点标注「代价开始显现，但已难以归因」。
- 两曲线之间的阴影区标注「认知—实际背离区」。
- 图下方加一条注记条：「单次决策：卸载在个体理性层面正确；长期累积：同一系列决策导向不合意结果」。
**要点**：感知阈值虚线是全图的关键，须清晰可辨；代价曲线在阈值以下的那一长段是本书全部论证的落点。

### 图2-3　自动化反讽的双重结构
**位置**：2.2.1 节，第二段之后
**类型**：双环闭合结构图
**结构**：
- 左环（任务分配之讽）：「不信任人的可靠性」→「以机器取代常规操作」→「异常情形留给人」→「人面对的是最困难的任务」→ 回指起点。
- 右环（能力维持之讽）：「人被设置为最终可靠性保障」→「人长期不参与常规操作」→「技能日渐生疏」→「保障本身的可靠性被削弱」→ 回指起点。
- 两环在中部共享一个节点：「自动化程度提高」。
- 图右侧加一行结论注记：「自动化程度愈高，留给人的任务愈难，而准备愈不足」。
**要点**：两环必须都是闭环（自我强化），共享节点居中，避免画成两条并列的流程线。

### 图2-4　缄默知识在认知卸载中流失的三条路径
**位置**：2.3.3 节，第四段之后
**类型**：三路径并行对照图
**结构**：
- 顶部为起点框「一项依赖缄默知识的任务被交付机器」。
- 向下分出三条并行路径：
  1. **不可寄存**：显性知识 →「写入文档/数据库/工具」→「仍存在于某处」；缄默知识 →「无处可写」→「无人实践后逐渐消散」。（此路径内部再作显性/缄默的对照）
  2. **依赖实践维持**：「不再亲自推敲比例」→「关于比例的手感不再被调用」；「不再亲自筛选材质」→「关于材质的直觉不再被激活」→ 汇入「取消运用＝取消能力」。
  3. **形成过程与效率目标冲突**：「工具消除低效试错」→「反复失败、无用尝试、被推翻的方案不再发生」→「缄默知识无从沉淀」。
- 三条路径底部汇入同一个结果框：「形成需长期浸润，退化只需持续闲置」，其下再接一个框：「不可自察：无法清点自己失去了何种说不出来的能力」。
**要点**：三条路径等宽并行，末端汇聚；最下方的「不可自察」框须与上方结果框在视觉上区分（如加虚线边框），因为它是本书区别于一般能力衰退的关键。

### 图2-5　四条理论脉络向认知韧性界定的汇聚
**位置**：2.5.1 节末
**类型**：四路汇聚图（本章总图）
**结构**：
- 左侧并列四个来源框，各标出脉络名称、核心贡献与适用限度（内容取自表2-1）：
  1. 元认知与认知卸载 → 贡献：外部化的机理；判断卸载不可回取
  2. 自动化研究 → 贡献：能力因闲置而退化；设计领域更难察觉
  3. 缄默知识理论 → 贡献：何种能力最易流失；代价的阶段依赖性
  4. 韧性理论 → 贡献：损耗条件下功能维持的框架；可设计性
- 中部为一个收束节点：「认知韧性（本书界定）」。
- 右侧展开为三个维度框：元认知监控、自主验证行为、创作能动性，并各自用虚线回连至其主要来源脉络（监控←脉络1，验证←脉络2，能动性←脉络3），脉络4 以另一种线型连向中部节点，注明「提供描述框架而非单一维度」。
**要点**：脉络 4 的连线方式须与前三条区分，否则会误读为四脉络各出一维；三维度只有三条，第四条脉络贡献的是框架本身。

### 图2-6　认知韧性三个维度的递进关系及两种分离情形
**位置**：2.5.3 节末
**类型**：递进链 + 两处断点标注
**结构**：
- 主链自左向右：「元认知监控（前提）」→「自主验证行为（手段）」→「创作能动性（结果）」，箭头依次相连，下方注记「正常情形下三者同向变动」。
- 在第一个箭头处标出断点一：**觉察而不验证**，旁注「知晓依赖，但因工期压力或核验成本而放弃核验 → 问题不在意识而在条件 → 对策指向流程与制度」。
- 在第二个箭头处标出断点二：**验证而无主张**，旁注「核验了每一项技术细节，却对审美取向与意义指向全无立场 → 止于技术性正确而不及价值性判断 → 易被误认作专业素养良好」。
- 图底部加一行警示注记：「三个维度须分别测量，不宜合成为单一综合分数」。
**要点**：两处断点用同一种断口符号标注在箭头上，而非另起两条支线，以保持「分离发生在传导环节」这一含义。

## 三、修订说明

### 3.1 语体改写（按指南 §1.1–1.4）

原稿为文言化论证语体，本次已全面改写为范本的现代学术论著语体。主要替换如下：

| 原稿用语 | 改后 |
|---|---|
| 凡此皆／凡此三者／以上三者皆 | 以上问题均／以上三者均 |
| 惟须指出／惟须强调／惟 | 但需要指出的是／但需要强调的是／但 |
| 是故／职是之故 | 因此 |
| 要之 | 由此可见／换言之 |
| 其缘由在于／其理由在于 | 其原因在于 |
| 藉以 | 以 |
| 自……而言 | 就……而言 |
| 亦／皆／须／方能／颇为 | 也／均／须（保留少量）／才能／较为 |
| 姑称之为 | 即所谓／称为 |
| 尚未／未曾 | 尚未（保留）／未曾（保留于少数固定搭配） |
| 第一章／第四章…… | 第1章／第4章…… |

同时按范本节奏补入序次与连接：各处论证改以「首先／其次／另外／最后」推进，分条改以「第一，第二，第三，」标示，段末统一以「这意味着」「因此」「由此可见」「以上……表明」收束。
