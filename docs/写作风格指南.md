| 指标 | 样本 A（新书绪论） | 样本 B（既有专著） |
|---|---|---|
| 平均段长 | 199 字 | 245 字 |
| 平均句长 | 50 字 | 77 字 |
| 自称 | 「本书」48 次；「本文/本研究」0 次 | 「本文」92、「本研究」83、「本论文」26 次；「本书」4 次 |
| 序次词 | 「其一/其二/其三」28 次；「首先/其次」3 次 | 「首先/其次」64 次；「其一/其二/其三」0 次 |
| 文言标记 | 「须」29、「凡」12、「易言之」2、「要之」1、「职是之故」1、「有鉴于此」2 | 「须」13，其余为 0 |
| 图表引称 | 0 处 | 「（如图…所示）」137 处 |
| 图 / 表 | 无 | 153 图 / 48 表 |

**建议（并非必须，但强烈推荐）**：

1. **语体分区，而非全书统一**。绪论与第一至第三章（理论谱系、学理命题、边界判据）属论证性文字，沿用 A 的文言化学术散文；第四至第七章（衰减机制、干预策略、溯源制度、应用场域）一旦出现实验、量表、平台与案例数据，切换到 B 的实证报告语体。切换点放在章首导语之后，不在段中忽文忽白。
2. **自称统一为「本书」**。B 卷的「本论文/本文/本学位论文」三称混用是学位论文遗留，新书须一律改「本书」；引述具体操作时可用「本研究」指代某一次实验，但不得指代整部著作。
3. **图表体例全书统一按 B 卷执行**（详见第三、四节）。A 卷绪论目前一图一表皆无，这是与"既有模式"最大的偏离，需补（详见第八节待办清单）。

## 一、语言与文体特征（以 A 卷为准）

### 1.1 句法骨架

- **判断句先行，论据随后**。每段第一句给结论或给限定，其后才展开。例：「本节的考察指向一个基本判断：生成式人工智能对设计活动的影响，其要害不在效率的提升，亦不在形式语言的更替，而在于它触动了设计之所以成其为设计的根基。」
- **「不在于 X，而在于 Y」的排除式定义**，全稿高频，是核心修辞。变体：「其要害不在…亦不在…而在于…」「不是…而是…」。
- **三项并置**。凡列举，优先凑成三项，且三项之间须有逻辑序（时序、层级或因果），不是并列堆叠。例：「其一，它所接管的是判断本身…；其二，它的接管具有隐性…；其三，它的输出足够流畅可信…」并在其后立刻交代三者的关系：「前两项特征使卸载得以持续发生，第三项特征则使卸载难以被自我纠正。」——**列完必须收束，这是作者的固定动作**。
- **长句以顿号与分号切分**，单句 40–60 字为常态，最长不超过 90 字；不用括号插入长解释，改用破折号（——）作单向补充。
- **文言虚词有限量地使用**：须、凡、职是之故、易言之、要之、有鉴于此、姑称之为、尚须补充者、须先予说明者有二。密度约每 600 字一处，不可加密到每段都有，否则失真。

### 1.2 段落骨架

标准段 = 判断句 + 展开（2–4 句） + 转折或限定 + 收束句。约 200 字。三种典型段型：

- **命名段**：给一个新概念下名。「据此，本书提出并使用认知韧性这一核心概念，用以指称……」
- **辨析段**：与相邻概念划界。「此处须与传统意义上的风格模仿加以辨析。……前者是可以走出的路径，后者则是难以察觉的引力场。」
- **限度段**：主动交代论述边界。「最后须交代本节论述的限度。本节所做者为现象层面的描述与归纳……它足以确立问题的现实性，却不足以解释问题的发生机制。」

**「限度段」是作者最鲜明的写作特征之一**：每一节、每一章的收尾处，都主动声明本段论证能支撑什么、不能支撑什么，把未竟之处顺势推给下一章。后续各章必须保留这一动作。

### 1.3 语气与立场

- **拒绝技术悲观论的自我澄清**：「需要说明的是，本书无意汇入笼统的技术悲观论。」——先解除读者的预设误读，再推进。凡涉及价值判断的章节，均须有这样一句自我定位。
- **克制的效力声明**：「凡属推论者称其为推论，凡待检验者明言其待检验。」结论强度分级用词固定为：证明 > 表明 > 显示 > 提示 > 可推断 / 可猜测 > 尚不明确。**不得越级**。
- **不使用**：感叹号、反问句、第二人称、口语化比喻、"众所周知"、"毋庸置疑"。
- **可使用的比喻**须是可解释的结构性比喻，且用后立刻还原为学理表述。例：「前者是可以走出的路径，后者则是难以察觉的引力场」「其功能类似于解剖学的切片，而非对活体运动的描述」。

### 1.4 术语处理

- **中文术语首见时括注英文原文与缩写**：认知卸载（cognitive offloading）、多属性决策方法（Multi-attributes Decision Making）、层次分析法（Analytic Hierarchy Process，AHP）。缩写一经给出，此后只用缩写。
- **人名首见时中译名 + 括注外文与年份**：里斯科与吉尔伯特（Risko & Gilbert，2016）、弗拉维尔（Flavell，1979）、霍林（Holling，1973）。B 卷用「Ashby」「Rajan 教授」的裸外文写法，新书统一改为中译名 + 括注。
- **自造概念加引号首现，此后去引号**：「材料知识映射模型」→ 材料知识映射模型；判断保留区、认知卸载边界、认知韧性同理。

## 二、篇章结构骨架（以 B 卷为准）

### 2.1 全书层级

```
封面/书名 + 副题（——起首，楷体）
摘要（中文）→ 关键词（顿号或逗号分隔，5 项）
Abstract → Key words
目录 / 插图索引（分章列出）/ 附表索引（分章列出）
绪论（第 0 章，节号 0.1 … 0.6）
第 1 章 … 第 N 章
结论与展望（研究结论 / 主要创新点 / 反思与展望）
参考文献（一、英文参考文献；二、中文参考文献；各自再分 期刊论文 / 专著 / 学位论文 / 标准与政策文本）
附录 A 研究中使用的调查问卷（A1、A2、A3…）
```

### 2.2 标题层级与字号（Word 排版参数，两稿一致）

| 层级 | 格式 | 字体 | 字号 | 对齐 | 段前/段后 |
|---|---|---|---|---|---|
| 书名 | 设计判断的守界 | 黑体 | 22pt (sz 44) | 居中 | 240 / 120 |
| 副题 | ——…研究 | 楷体 | 14pt (sz 28) | 居中 | 0 / 600 |
| 章 | 第 1 章 绪论 | 黑体 | 15–16pt (sz 30–32) | 居中 | 240–480 / 360 |
| 节 | 1.1 研究背景 | 黑体 | 13–14pt (sz 26–28) | 左 | 360–400 / 200–220 |
| 目 | 1.1.1 社会发展对材料的需求 | 楷体/黑体 | 12pt (sz 24) | 左 | 240 / 160 |
| 小目 | 4.2.1.1 测试流程 | 宋体加粗 | 12pt | 左 | — |
| 正文 | — | 宋体 / Times New Roman | 12pt (sz 24) | 两端对齐 | 首行缩进 480（2 字符），行距 400（20 磅） |

章号与标题之间用全角空格或「　」（A 卷用「第一章　绪论」的全角空格式，B 卷用「第1章 绪论」）。**新书统一采用 A 卷的「第一章　绪论」全角空格式，章序用中文数字。**

### 2.3 章的固定结构（B 卷 4/5/6 章严格遵循，须继承）

1. **章首导语**（不编号，1 段，150–250 字）：本章任务 → 处理对象 → 方法路径 → 产出物。例：「探讨材料物理量与感知体验两者关系并构建相关理论模型是本文的核心目标。本章将基于已提取的…通过相关性分析法…最后，通过…案例对…进行论证。」
2. **节首导语**（1 句至 1 段）：「本节将基于组间相关性分析结果解释如何构建…」
3. **主体各目**
4. **本章小结**（单独一节，编号为 N.5 之类，1 段，200–300 字）：只复述本章做了什么、得到了什么，**不引入新论据、不出现新图表**，末句衔接下章。

### 2.4 节的内部推进节奏（五步，A 卷 0.2 节是范本）

1. **立必要性**——为什么必须先厘清这件事，不厘清则全书立论不成立；
2. **给分析框架**——提出分期 / 分环节 / 分层级，并**交代分类依据与它的局限**（「须先予说明者有二」「关于这一划分，须作两点说明」）；
3. **逐项展开**——每项内部同构：定义 → 特性 → 与前一项的分野 → 就本书主题而言意味着什么；
4. **横向比较**——「三个阶段的比较，可自四个维度展开」，并指出「诸维度之中，最具决定意义者是第 X 项」；
5. **归结并交代限度**——「要之，…是本书全部问题的技术根源」+「本节所做者为现象层面的描述与归纳…其机制层面的解释留待第四章」。

> 这套节奏是作者最核心的"语言逻辑"。**分类之后必自陈分类的限度，比较之后必指认最关键的那一维，归结之后必声明尚未做到的事**——三个动作缺一则不像。

### 3.2 图题格式（严格三行，图**下**居中）

## 四、表格：放什么，怎么放

### 4.1 表题格式（表**上**居中，与图相反）

```
表 4-2 十二项被试产品材料样本的色彩物理量测试结果
Results of Color Physical Quantities of 12 Material Samples
（表格来源：作者自绘）
<表体>
```

- 续表：`表 4-2 …测试结果（续）`，续表**不重复**英文题与来源行，但**须重复表头行**（B 卷部分续表漏了表头，见第八节待办）。
- 三线表为主；统计软件输出表（如组间效应检验、事后多重比较）保留 SPSS 原始表头与脚注（`*. 平均值差值的显著性水平为 0.05。`）。
- 表内数值：**统一保留两位小数**并在正文中声明「结果仅保留小数点后两位」；量纲写在表头或首次出现的正文括注中，如 `密度（380 kg/m³~8930 kg/m³）`。
- 空单元格表示"不相关/不显著"时，须在表前一段说明这一约定。

## 五、实验与数据的呈现程式（B 卷第 4–6 章的定式）

### 5.1 一次量化实验的七段式

按顺序、不跳步：

1. **要素/变量的提取** —— 说明从何而来（文献分析法 / 德尔菲法 / 主成分分析法），给筛选原则（编号「第一…第二…第三…第四…」）。
2. **问卷或量表设计** —— 结构（人口统计变量 + 主体量表）、量表类型与锚点（「1 至 5 分别对应"非常不重要"…"非常重要"」）、来源（「均由 Karana 教授研究中的英文原文翻译而来」）、专家审校（「针对'题项文字表达是否准确'…进行了全面审查」）、**小样本预测试的信效度**。
3. **受试者筛选与样本量论证** —— 招募渠道（微信群/朋友圈/QQ 群 + 滚雪球抽样）、纳入标准、**同类研究的样本量先例**、随机分配、G*Power 事后检验力核验（写成 `Sample size=30, α err prob.=0.05, Effect size=0.5, Power=0.86`）、知情同意与酬谢、伦理声明。
4. **实验环境与流程控制** —— 温湿度（24℃、50%）、光照、噪声（3M-1426 隔音耳罩）、坐姿与手指姿势、样本呈现顺序随机、样本间清洁、单人时长（10–15 分钟）。**控制变量写得越具体越像作者本人**。
5. **结果的描述统计** —— 回收量 / 有效量 / 剔除规则（「填写时间少于 20 秒的问卷将被剔除」）、信效度（`Cronbach's α=0.913，KMO=0.872，Bartlett 球形度检验 0.000（P<0.05）`）、受试者构成。
6. **图示 + 表格双呈现** —— 先箱线图/折线图看分布，后均值表给定论，正文逐项点名极值（「M3 被认为是最易破碎的而 M8 则被认为是最坚固的」）。
7. **推断统计** —— 固定链条：**正态性（S-W + 直方图 + P-P 图）→ 方差分析（F、P）→ 方差齐性（Levene）→ 事后检验（齐用 S-N-K，不齐用 Tamhane T2）→ 结论与下一步指向**。每一步都先讲判据（「若 P 值不呈显著性（p>0.05）则说明符合正态分布」）再给结果。

### 5.2 统计结果的行文模板（可直接套用）

- 信效度：`结果显示：Cronbach's α 系数为 0.913，KMO 值为 0.872，Bartlett 球形度检验值为 0.000（P＜0.05）。这表明该问卷的信度及效度都极高，即……`
- 方差分析：`表 5-4 揭示了……组间效应检验的结果：12 项不同被试样本材料（F=0.409，P=0.944）及 5 种不同材料感官体验要素（F=1.298，P=0.285）的 P 值均大于 0.05，因此两者对受试者量化评估结果都无显著影响。`
- 事后检验：`当显著水平为 0.05 时，被试产品材料样本 M8（铁）分别与 M4（松木）、M6（PVA）及 M11（棉布）在……中呈显著差异。`
- 相关性分级（**固定七级，须原样沿用**）：不相关（−0.30＜r＜0.30）、完全正相关（r=1）、强正相关（0.75≤r＜1）、弱正相关（0.30≤r＜0.75）、完全负相关（r=−1）、强负相关（−1＜r≤−0.75）、弱负相关（−0.75＜r≤−0.30）；且「相关性系数需满足显著性，本研究选择 P＜0.05」。
- 相关性叙述：`（1）材料粗糙程度与密度（−0.77）、弹性模量（−0.77）及光泽度（−0.84）呈强负相关，与比热容（0.68）呈弱正相关……` → 紧接一段 `由此可见，…` 的意义解读 → 再接一句**与既有研究的对照**（`该相关性分析结果与 Shirado 及 Maeno 两人认为"…"的研究结论保持一致` / `本论文的相关性研究结果也与过往研究结论存在部分差异…而造成这一结果的主要原因很可能与…有关`）。
- t 检验：`样本 T 检验结果显示 P=0.01（P＜0.05），Cohen's d=1.43，表明 A 与 B 两组数据呈显著差异。其中，A 组…（Amean=0.35）明显少于 B 组（Bmean=0.95）。`
- 承认未解：`但……的方差分析中并未明显体现不同要素间的显著差异，而在相关性分析中却发现……，其中原因暂不明晰。` ——**保留这类诚实的悬置，是作者的可信度来源，不要为了圆满而删。**

### 5.3 案例验证的三重评估结构（B 卷 6.4 的做法，值得复用）

对同一件产出（平台/方法/工具），从三个互不重叠的角度各做一次量化验证：

1. **效率**——专业使用者 A/B 组对照，记录日志总时长，t 检验；
2. **终端用户偏好**——真实目标人群（学龄前儿童）用表情卡片量化，报告最大值/最小值/均值/标准差；
3. **利益相关者接受度**——决策者（家长）用 Likert 接受度问卷（态度 ATT + 使用意向 ITU），分项均分 + 组均分。

最后以「综上所述，本节以…为例，以…、…及…三项作为评估标准，以论证……」收束，并主动指出验证暴露的不足（「材料信息多样性仍有待持续增加和丰富」）。
