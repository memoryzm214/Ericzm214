# 写作风格与体例指南

> 依据《产品设计中材料物理量与感知体验关系研究》全稿归纳而成，用于后续书稿各章的撰写与修订。
>
> 原稿规模：262 页，13,988 词 / 21,792 字符，7 章 + 参考文献 + 附录 A；**153 幅图、48 张表**。
>
> 本指南的目标：把该稿中已经稳定成型的语体、篇章逻辑、图表体例与实验数据呈现程式固定下来，使新书各章可直接套写而保持同一副笔调。

## 一、语言与文体特征

### 1.1 语体定位

现代学术论著语体，不用文言虚词，不用文学化修辞。核心气质是**"把每一步都交代清楚"**：凡做一个动作，先说为什么做、依据什么做、怎么做、做出来是什么、这说明什么。全稿的可信度来自过程的可复核，而非语言的漂亮。

统计特征（正文约 12.7 万字，剔除图表与题注后）：

| 项目 | 实测 |
|---|---|
| 平均段长 | 245 字（实验流程类长段可达 1,200 字） |
| 平均句长 | 77 字（中位 64） |
| 「因此，」 | 103 次 |
| 「此外，」 | 106 次 |
| 「另外，」 | 83 次 |
| 「但」/「然而」 | 103 / 18 次 |
| 「第一，」「第二，」「第三，」 | 26 / 26 / 21 次 |
| 「首先」「其次」 | 37 / 27 次 |
| 「其中，」 | 54 次 |
| 「可能」 | 73 次 |
| 「有必要」 | 21 次 |
| 「值得注意」 | 13 次 |
| 「（如图…所示）」/「…如表…所示」 | 137 处 |
| 「这意味着」/「由此可见」/「综上所述」 | 13 / 9 / 7 次 |

### 1.2 段落骨架

标准段 = **背景或前提句 → 展开（2–5 句）→ 转折限定 → 收束句**。四种典型段型：

1. **综述段**（第 1、2 章为主）：`[人名/机构/头衔] + 认为/提出/构建了 + [观点或模型] + [尾注]`，一段容纳 2–4 位研究者，末句以「由此可见」「这意味着」综合出本书要用的那一点。
   > 例：「Dennis P. Doordan 认为设计的目的是将抽象概念转化为具体形式，并认为与材料相关的研究应从制造（fabrication）、应用（application）与欣赏（appreciation）三个方面进行考量[]。……由此可见，材料感知体验应起码包含描述外观美学特征的材料感官体验、描述知觉与联想特征的材料知觉体验，以及与个体情感相关联的材料情感体验三个部分共同构成。」

2. **原则段**：先给数目，再逐条编号落实。
   > 「本书将遵循以下四项原则，以实现被试产品材料样本的筛选：第一，……；第二，……；第三，……；第四，必须避免选择易燃易爆或具有强烈腐蚀性和毒性等一切对人体、设施及环境等可能易造成安全隐患的实验材料。」

3. **操作段**（实验章的主力段型，可长至千字）：环境 → 预处理 → 步骤 → 控制措施 → 时长，一句一动作，每个数字都写出来（24℃、30%、120mm×120mm×3mm、40W 热熔胶枪、3M-1426 隔音耳罩、10–15 分钟）。
4. **结果段**：`[表 X 显示了……] → [逐项点名极值] → [统计检验结论] → [这表明……]`。

### 1.3 固定句法习惯

- **目的状语前置**：为确保…／为避免…／为提高…／为便于…／为深化…，句首出现约 40 次。凡新增一个动作，先说它防的是什么或求的是什么。
- **「其中，」承接细节**（54 次）：给出总体后，用「其中，」拎出需要单说的那一项。
- **「但」转折密度高**（103 次）：几乎每个正面陈述后都跟一个限定。这是该稿最稳定的节奏——**给一个结论，立刻给它划边界**。
- **同位语式定义**：`[术语]是[定义]，[进一步说明]`，术语首见时括注英文与缩写：物理量（physical quantities）、多属性决策方法（Multi-attributes Decision Making）、层次分析法（Analytic Hierarchy Process，AHP）、混合研究方法（mixed methods）。缩写一经给出，此后只用缩写。
- **专家意见直接转述**：「产品设计专家表示：PETG、ABS、TPU、PC 与 PVA 五种塑料的感官体验较为相似，仅保留其中几种即可」「材料工程师表示若需要使用白光干涉仪……需保证材料表面粗糙度小于 300μm」。这类转述让筛选决策可追溯，须保留。
- **不使用**：感叹号、反问句、第二人称、"众所周知"、"毋庸置疑"、无解释的比喻。

### 1.4 结论强度与谨慎表达

用词分级固定，**不得越级**：

```
证实 / 证明  >  表明 / 显示  >  结果显示  >  这意味着  >  可推断 / 初步推断  >  可能 / 很可能  >  尚不明确
```

- 「可能」全稿 73 次，是主力谨慎词：「材料感官体验差异**可能**与材料自身的弹性模量、导热系数……相关」。
- **老实承认讲不通的地方**，这是该稿可信度的重要来源，须保留：
  - 「但需要注意的是，材料情感体验的方差分析中并未明显体现不同要素间的显著差异，但在相关性分析中却发现各材料情感体验要素间呈明显相关性，**其中原因暂不明晰**。」
  - 「而造成以上差异的原因**目前尚不明确**。」
  - 「造成这一结果的主要原因**很可能与**实验中被试产品材料样本色彩过于单一有关。」
- **推测须给出机理**：「这可能是由于以上材料已被广泛应用于儿童产品市场当中，受试群体对此类材料相对熟悉致使接受度相对较高。」

### 1.5 自称

原稿「本文」92 次、「本研究」83 次、「本论文」26 次、「本著作」4 次、「笔者」1 次，五称混用，是学位论文遗留。

**新书统一规则**：
- 指整部著作 → **「本书」**；
- 指某一次具体实验或某一项具体工作 → 「本研究」；
- 「本论文」「本学位论文」「笔者」**一律不用**。

## 二、篇章结构骨架

### 2.1 全书层级

```
摘要（中文）→ 关键词（逗号分隔，5 项）
Abstract → Key words
目录 / 插图索引（按章分组）/ 附表索引（按章分组）
第 1 章 绪论
第 2 章 …理论基础
第 3 章 …研究方法
第 4 章 … / 第 5 章 … / 第 6 章 …（实证与应用）
第 7 章 结论与展望（研究结论 / 主要创新点 / 反思与展望）
参考文献（一、英文参考文献；二、中文参考文献；各区再分 期刊论文 / 专著 / 学位论文 / 标准与政策文本）
附录 A 研究中使用的调查问卷（A1、A2、A3…）
```

### 2.2 标题层级与排版参数

| 层级 | 格式 | 字体 | 字号 | 对齐 |
|---|---|---|---|---|
| 章 | 第 1 章 绪论 | 黑体 | 15–16pt | 居中 |
| 节 | 1.1 研究背景 | 黑体 | 13–14pt | 左 |
| 目 | 1.1.1 社会发展对材料的需求 | 黑体/楷体 | 12pt | 左 |
| 小目 | 4.2.1.1 测试流程 | 宋体加粗 | 12pt | 左 |
| 正文 | — | 宋体 / Times New Roman | 12pt | 两端对齐，**首行缩进 480（2 字符）**，行距 400（20 磅） |
| 图题/表题 | — | 宋体 / Times New Roman | 小五 | 居中 |

### 2.3 章的固定结构（第 4、5、6 章严格遵循，须继承）

1. **章首导语**（不编号，1 段，150–250 字）：本章任务 → 处理对象 → 方法路径 → 产出物。
   > 「探讨材料物理量与感知体验两者关系并构建相关理论模型是本文的核心目标。本章将基于已提取的材料物理量量值及感知体验量化数据，通过相关性分析法……。此外，为进一步深化理论模型的应用价值，本章还阐述了……。最后，通过……案例对……进行论证。」
2. **节首导语**（1 句至 1 段）：「本节将基于组间相关性分析结果解释如何构建产品设计中材料物理量与感知体验关系的材料知识映射模型。」
3. **主体各目**
4. **本章小结**（单独一节，1 段，200–300 字）：只复述本章做了什么、得到了什么，**不引入新论据、不出现新图表**，末句预告下章。
   > 「本章通过相关性分析法揭示了……，获取了……。此外，为深化模型的应用价值，本文基于该理论模型内容构建了……。最后，本文还以……为产品设计实例，通过……、……及……的评估，证实了……的可用性和有效性。」
   > 「……本文将在第 3 章节中详细叙述挖掘产品设计中材料物理量及感知体验关系的具体研究方法。」

### 2.4 三类章的内部节奏

**A. 绪论章**：研究背景（宏观需求 → 市场需求 → 尚待开发的空白）→ 国内外研究现状（先说检索策略：关键词、数据库、年限、命中数 107 项，再给分布图，再分三块评述，最后「研究现状总结」用第一/第二/第三列出待解问题）→ 研究目标与意义（理论层面 / 实践层面各一段）→ 研究内容及组织架构（先给构架图，再逐章一段「第 X 章，[章名]。……」）。

> 检索策略必须写实：「以"产品设计（product design）"、"产品材料（product materials）"……为关键词，分别在知网、万方、维普网、Web of Science、ProQuest 及 Google Scholar 等国内外文献数据库中筛选出自 2000 年起至今的相关学术成果共 107 项。」

**B. 理论基础章**：先在章首导语把本章要解决的子问题编号列出（「第一，如何有效提取……；第二，如何获取……；第三，如何对两者间的相关性进行有效分析并构建理论模型」）→ 每节按"概念定义 → 他人研究综述（配他人模型重绘图）→ 本书的综合判断"推进 → 末段以「由此可见」给出本书自建的框架 → 本章小结。

**C. 实验/应用章**：见第五节的七段式。

### 3.2 图题格式（三行，图**下**居中）

```
图 4-13 十二项被试产品材料样本的表面轮廓图
Surface Profile of 12 Material Samples
（图片来源：作者自绘）
```

- 第 1 行：`图<章>-<序> <中文题>`
- 第 2 行：英文题，实词首字母大写（Title Case）
- 第 3 行：来源，五种固定写法：
  - `（图片来源：作者自绘）`——自制示意图、模型图、统计图
  - `（图片来源：作者拍摄）`——实物照片、实验现场
  - `（图片来源：根据论文 XXX 内容整理）`——重绘他人模型
  - `（图片来源：作者截图）` / `（图片来源：测量结果截图）`——软件与仪器截图
  - `（图片来源：https://…）`——网络图片
- **组图**：题名末尾括注方位，`图 4-2 基于色差仪测量口径大小的测试区域（左）`、`图 6-38 （左上）NAO 机器人参与儿童在学校中的日常教学`；或 a/b 分注，`（图 5-4a：受试者 A 实验过程，图 5-4b：受试者 B 实验过程）`。同组多幅共用一个来源行。
- **跨页续图**：`图 5-5 ……感官体验量化结果（续）`，续图不重复英文题与来源行。
- 多幅排布用**无框表格**承载以保证对齐。

### 3.3 插图索引

书前设「插图索引」，按章分组，格式 `图1-1  材料在各行各业中的应用    1`（图号与题名间两空格，右端页码）。附表索引同理。

## 四、表格：放什么，怎么放

### 4.1 表题格式（三行，表**上**居中，与图相反）

```
表 4-2 十二项被试产品材料样本的色彩物理量测试结果
Results of Color Physical Quantities of 12 Material Samples
（表格来源：作者自绘）
<表体>
```

- 续表：`表 4-2 ……测试结果（续）`，**不重复**英文题与来源行，但**须重复表头行**。
- 统计软件输出表保留原始表头与脚注（`*. 平均值差值的显著性水平为 0.05。`）。
- 数值**统一保留两位小数**，并在正文中声明「结果仅保留小数点后两位」。
- 量纲在表头或正文首次出现时括注范围：`密度（380 kg/m³~8930 kg/m³）`、`弹性模量（0.28 GPa~100 GPa）`。
- 空单元格若表示"不显著/不相关"，须在表前一段说明该约定。

### 4.2 什么内容进表

| 表的功能 | 例 |

| 原始测量数据 | 表 4-2 五区域两次测试全量数据 |
| 汇总均值 | 表 4-3 五类色彩物理量平均值；表 4-8 章末物理量总表 |

## 五、实验与数据的呈现程式

### 5.1 一次量化实验的七段式（按顺序，不跳步）

1. **要素 / 变量的提取**——说明从何而来（文献分析法 → 德尔菲法 → 主成分分析法，逐级收敛），给筛选原则（「第一…第二…第三…第四…」）。
2. **问卷或量表设计**——结构（人口统计变量 + 主体量表）、量表类型与锚点（「"1"至"5"分别对应"非常不重要"、"比较不重要"、"一般"、"比较重要"及"非常重要"」）、来源（「均由 Karana 教授针对材料体验相关研究中的英文原文翻译而来」）、专家审校（「针对"题项文字表达是否准确"、"语句内容是否通俗易懂"及"题项之间是否符合逻辑"进行了全面审查」）、**小样本预测试的信效度**。
3. **受试者筛选与样本量论证**——招募渠道（微信群 / 朋友圈 / QQ 群 + 滚雪球抽样）、纳入标准、**同类研究的样本量先例**（「Wongsriruksa 等人招募了 40 名……Chen 等人招募了 18 名……」）、随机分配、G\*Power 事后检验力核验、知情同意与酬谢、伦理声明（「本实验不涉及任何损害受试者身心健康的内容，所有数据将匿名收集并进行保密处理，且仅用于学术研究」）。
4. **实验环境与流程控制**——温湿度（24℃、50%）、光照、噪声（3M-1426 隔音耳罩）、坐姿与手指姿势（食指与中指指腹、从左至右滑动）、样本呈现顺序随机、样本间清洁（酒精湿巾去油脂）、单人时长（10–15 分钟）。**控制变量写得越具体越像本人手笔。**
5. **结果的描述统计**——回收量 / 有效量 / 剔除规则（「填写时间少于 20 秒的问卷将被剔除」）、信效度、受试者构成。
6. **图示 + 表格双呈现**——先箱线图 / 折线图看分布，后均值表给定论，正文逐项点名极值。
7. **推断统计**——固定链条，每步先讲判据再给结果。

### 5.2 统计链条（不可省步）

```
正态性检验：S-W + 正态分布直方图 + P-P 图
        ↓（P>0.05 判定服从正态）
方差分析 ANOVA：报 F 值与 P 值
        ↓（P<0.05 判定存在显著差异）
方差齐性检验：Levene
        ↓
事后检验：方差齐 → S-N-K；方差不齐 → Tamhane T2
        ↓
比较呈显著差异样本的物理量 → 初步推断相关性 → 交由相关性分析章深入
```

判据须写明：「在数据分析过程中，若 P 值不呈显著性（p 值大于 0.05 或 0.01）则说明符合正态分布，反之则不符合。在现实研究中，数据通常很难满足标准的正态性分布，因此需要结合正态分布直方图及 P-P 图辅以判断。」方法选择的理由也须写明：「LSD 虽然发现组内及组间细小的差异，但常因为过于灵敏而极易造成'假阳性'的错误判断。因此，当方差为齐时，本研究将使用 S-N-K 法进行检验以确保研究结论无误。」

  1. 分条列系数——`（1）材料粗糙程度与密度（−0.77）、弹性模量（−0.77）及光泽度（−0.84）呈强负相关，与比热容（0.68）呈弱正相关……`

### 5.4 案例验证的三重评估结构（第 6.4 节的做法，值得复用）

对同一件产出（模型 / 平台 / 方法），从三个互不重叠的角度各做一次量化验证：

1. **效率**——专业使用者 A/B 组对照，日志记录总时长，t 检验；
2. **终端用户偏好**——真实目标人群（学龄前儿童）用表情卡片量化，报最大值 / 最小值 / 均值 / 标准差；
3. **利益相关者接受度**——决策者（家长）用 Likert 接受度问卷（态度 ATT + 使用意向 ITU），分项均分 + 组均分。

三项做完以「综上所述，本节以……为例，以……、……以及……三项作为评估标准，以论证……」收束，并**主动指出验证暴露的不足**（「产品材料推介平台中的材料信息多样性仍有待持续增加和丰富」）。
