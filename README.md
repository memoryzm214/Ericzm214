## 使用

上课用浏览器打开 `slides.html`（**`assets/` 需与它同目录**），或直接双击 `slides-single.html`（图片已内嵌，单文件即可）。
方向键翻页，`O` 总览，`H` 收侧栏，`F` 全屏，`D` 深色。

## 修改

- 文字与图片：直接改 `slides.html` 的 HTML 段落，改完重新生成单文件版与 PDF
- 配色：改文件顶部 `:root` 中的色值，深色模式在紧随其后的两个同名变量块
- 时间轴 / 循环图 / 象限图的数据：在文件末尾 `<script>` 中的对应数组

注意：脚本段内的中文引号必须使用全角 `“ ”`，用半角 `"` 会截断 JS 字符串。
